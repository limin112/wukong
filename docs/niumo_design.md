# 《火焰山 · 牛魔》战斗与镜头设计（草案）

题材取自《西游记》原著（公版）：火焰山、牛魔王、芭蕉扇。造型全部原创，不沿用《黑神话》的任何角色、关卡、美术与音乐。
概念图：`concept/niumo_*.png`（造型以 `niumo_boss_b` 为准）。

## 一、操作（只用键盘）

| 键 | 作用 |
|---|---|
| W A S D | 移动 |
| 空格 | 翻滚（有无敌帧）；按住奔跑 |
| J | 轻击：三段棍法 |
| K | 重击：按住蓄力，松开砸下；蓄满能砸碎熔岩裂口 |
| L | 格挡：按住挡；被打中前一刻按下即弹反 |
| I | 芭蕉扇：扇灭地上的火、把他喷来的火吹回去（消耗法力） |

镜头全自动：始终把猴子和牛魔王当前威胁的部位框在一起，不需要鼠标（鼠标可选）。锁定也自动，对准最近的弱点（手、膝、头）。

## 二、规模

猴子约 1.5 米；牛魔王坐着约 22 米（猴子的 15 倍），站起来约 40 米。

## 三、一阶段「坐山」（满血 → 半血）

他不起身，坐着打。每招都有预兆：

1. 横扫：混铁棍贴地横扫半个战场。预兆是棍子抬起、熔岩从棍上滴落。翻滚穿过，或跳上石台。
2. 砸棍：竖砸，落点沿线裂开喷熔岩，带延迟，别急着滚。
3. 拍掌：地上先出现巨大的手影，两秒后拍下；拍完手掌压在地上两秒，这是主要的输出窗口，打手背上的熔岩裂口。
4. 吐火：扫过全场的火焰。躲到玄武岩柱后面，或用芭蕉扇（I）吹回去烧他。
5. 抓：在他正前方待太久，他会伸手来抓。翻滚躲开；被抓住会被捏起重摔。

弱点：两只手背、两个膝盖上的熔岩裂口。打碎两个，他会痛得俯下身，头砸到地上。
处决「牵牛鼻子」：冲到他头前按 J，猴子一把揪住铁鼻环，抡起铁棒砸在他额头上。

## 四、转阶段「山崩」（约 10 秒过场）

半血时他仰天长啸，背后的山体裂开，熔岩喷涌；他双手撑地，把自己从山里拔出来、站起身。镜头从他的蹄子一路仰到被火映红的天，他的头隐在烟里。战场地面塌陷，变成熔岩湖上的几块浮岩。

## 五、二阶段「现出原身」（半血 → 0）

他站着，更大、更快：

1. 踏地：牛蹄踩下，熔岩浪向四周推开。翻滚，或跳到高处。
2. 角扫：低头用牛角横扫整片浮岩。
3. 火雨：喷发的火山落下熔岩弹，地上先亮落点光圈。
4. 掷棍：把混铁棍当标枪掷来，插在地上变成一根新的石柱，可以躲在后面。
5. 芭蕉扇更重要：扇灭浮岩上的火，开出落脚点。

打碎他两个膝盖，他单膝跪下，头再次低到够得着的高度，最后一次「牵牛鼻子」处决。

## 六、结局

他倒进熔岩湖，火山慢慢熄灭。八百里火焰山千年来第一次下雨。最后一个镜头：猴子坐在他露出湖面的牛角上，雨打在金面具上。字幕「火焰山 · 熄」。

## 七、开场 MV 分镜（约 50 秒）

用章回小说的形式开场，先出一张原创回目卡：「第一回　火焰山千年不熄　美猴王一棒问山」。

1. 黑场，只有风声和火声。灰烬飘落在烧焦的大地上。字幕：「八百里火焰，四周围寸草不生。」（原著原句）
2. 山脊上，一只猴子的剪影扛着铁棒走过烧红的天际线。
3. 火山口远景，尽头那座「山」（主视觉 A 的构图）。字幕：「人说，那不是山。」
4. 熔岩河特写，热浪扭曲；山的肩膀上，火灰缓缓滑落：山在呼吸。
5. 猴子走到他膝下，仰拍（主视觉 B 的构图），混铁棍像擎天柱。
6. 熔岩色的眼睛睁开。字幕：「它坐在这里，已经一千年。」
7. 一声长啸，火光冲天，标题「火焰山 · 牛魔」，开打。

## 八、音乐

- 开场：风声、低沉的喉音吟唱、一支唢呐似的独奏，最后大鼓一声落下。
- 一阶段：大鼓、锣、钹为主，节奏厚重。
- 二阶段：鼓点加倍，唢呐和合唱顶上去。
- 结局：雨声和一把古琴似的拨弦。

## 九、制作顺序

1. 定稿造型（猴子、牛魔王站姿、铁棒、同框主视觉）。
2. Tripo 建模和绑骨：牛魔王按站姿建模，坐姿用我们的动作系统摆；猴子；铁棒。
3. 火山口场景：地形、流动的熔岩、玄武岩柱、火灰、热浪扭曲。
4. 战斗：猴子棍法和新键位、牛魔王的坐姿招式、弱点与处决。
5. 过场与音乐：开场 MV、山崩、结局，新的中式配乐。
6. 测试和打磨。

基于从原工程带来的引擎（锁定、打击感、音效系统、MV 系统），入口 `index.html`。
