# 《火焰山 · 牛魔》美术圣经

总导演定稿。所有概念图、模型、场景、光影、镜头、音乐都以这份为准。玩法与分镜见 `docs/niumo_design.md`，模块接口见 `docs/niumo_architecture.md`。

## 总基调

衰败的神话，在一天里最美的那一刻上演。压抑、沉默、古老，不是热血爽片；但画面是明亮的（2026-11-13 用户定稿：「整体太暗，天空要亮，要有 HDR 的感觉」）。八百里火焰山的黄昏：太阳压在冒烟的火山后面，整片天是烧着的云，地上是长长的影子。厚重来自尺度、构图和节奏，不来自把画面压黑。

## 色板

- 天：地平线熔金到绯红，天顶青灰作补色；烟柱逆光，有亮边。
- 地：灰烬的暖灰、焦褐、暗铁锈红；熔岩橙只在裂缝、伤口、河道。
- 人：牛魔王是骨白与亮金；悟空是黑铁、旧金、暗红披风，戴光滑无纹路的全脸金面具（只有眼缝；耳朵是肉色，不在面具里——`polishMask` 按脸宽 `MASK_SIDE` 截住）、额上火焰金箍、棕红毛发（2026-11-17 用户定）。牛魔王冲撞时现原形：一头巨大的白牛（白毛、金尖黑角、金鼻环、四蹄金环）。
- 禁止：把画面压成一片黑；也不要过曝发白。暗部要有层次，亮部留给太阳、熔岩和金子。

## 牛魔王（白牛武僧，以 `concept/niumo_w_bull_a6.png` 为准，2026-11-13 用户定稿）

- 原著本相是大白牛：骨白色的皮，带旧伤疤，颌下和颈部有粗硬的白鬃；一对巨大的乌黑弯角，角尖包一层薄金。
- 身材极其强壮：隆起的斜方肌和肩、厚胸肌、八块腹肌、粗壮的手臂和青筋。胸、肩、双臂大面积裸露。
- 富贵只体现在面具和装备上，身上是僧人装束。克制，不要土豪感（不要满身宝石、念珠成串、织锦龙袍）：
  - 金牛脸面具：一整块亮金，细刻云纹，额头一颗小暗红石，金鼻环；
  - 混铁棍：乌黑陨铁棍身，嵌金色云纹，厚重的雕花金箍，两头金帽雕成牛头；
  - 护腕：金和乌铁，刻云纹，挂着天庭的断锁链。
- 僧人装束：暗锈红和炭灰的拼块袈裟，只搭左肩，裹住腰和腿；粗麻绳腰带；一串大颗深色木念珠。
- 他身上的亮金只出现在面具、棍和护腕上，其余部分是骨白、暗红和炭灰。

## 悟空（黑金猿猴战神，以 `concept/niumo_w_monkey7_front.png` 为准，2026-11-13 用户定稿）

- 一张旧金的全脸面具：傩面与青铜礼器的意思，冷峻的猿脸，眉心一簇火焰纹连着金箍；面具后面看不见眼睛。金棕色的毛和尖耳从面具两侧露出来。与牛魔王的金牛面具相对。
- 黑金重甲，像实战用过的装备：黑铁甲片层层叠叠，边缘磨损、划痕、氧化，旧金包边。
  - 左肩一个夸张的金色兽首（龙/狻猊）肩甲，右肩是叠片肩甲；
  - 胸甲上有战鼓样的圆形浮雕和兽面纹，腰间一张吞兽面；
  - 暗红丝绳从肩斜拉到胸腹，打着结；腰间挂着金属饰件、布条、流苏；
  - 下身是深色战裙配鳞甲护腿，膝上兽面护膝，黑靴旧金包头。
- 暗红披风从两肩垂到膝下，下摆是一道干净的弧线、镶一条细金边（2026-11-17 用户：披风要帅气，不要破烂；模型自带的撕裂下摆在着色器里裁掉，`monkey.js capeHem`），从背后看是他最醒目的颜色；手腕挂着五行山的断锁链。**没有尾巴**（绑骨后会出问题，用户要求去掉）。
- 金箍棒（2026-11-17 用户：要真正的如意金箍棒）：两头是 Tripo 生成的金箍——高浮雕的盘龙祥云、顶上一枚祥云纹圆帽（概念图 `concept/niumo_w_jgb_cap.png`，模型 `assets/models/niumo_jgb_cap.glb`，两头共用一个件）；中间是红黑的锻铁棍身（`monkey.js createStaff({ cap })` 拼起来）。整根棍子直接让 Tripo 生成会变成两根平行的细条，所以只生成粗短的端头。文件缺失时退回程序生成的金箍。
- 与牛魔王的对照：他是黑金战神，牛魔王是白牛武僧；一黑一白；牛魔王戴一张干净抛光的金面具，悟空露出真脸。

## 场景：火山口里的古祭坛

- 牛魔王盘坐在火山口尽头一座半埋在火山灰里的古祭坛上。
- 战场散布着断裂的石碑（刻着褪色的符文）、倒塌的石牌坊、插在地上锈蚀的兵器和骸骨，那是之前的挑战者。
- 熔岩河表面结着黑色的硬壳，裂缝和流动的边缘发光。
- 火灰像雪一样缓缓飘落（暖灰色，逆光时发亮）；远处还有更多冒烟的火山，太阳落在其中一座的烟里。
- 二阶段（山崩）：山体裂开，熔岩真正喷发，天更炽烈。结局下雨，雨把一切冲成冷的灰蓝色，蒸汽升起；冷，但不黑。

## 光影

- 主光是低角度的暖色太阳（在牛魔王右肩后方，带阴影），冷色天光补光，熔岩底光。天空着色器输出线性 HDR，太阳核心远亮于白，靠泛光自然溢出；环境反射用同一片天空生成。
- 巨物逆光：牛魔王有一圈金色的轮廓光，正面靠天光和地面反光读出来。悟空有一盏只照他的主光，站在巨人的影子里也看得清；需要剪影时（山脊镜头）把它关掉。
- 热浪扭曲、暖色的霾（大气透视）让巨物的远处发虚，显得更大。
- 泛光留给太阳、熔岩裂缝、眼睛、受击火花和喷发。

## 镜头

- 巨物用仰拍；人物多放在画面下三分之一；巨物的头常常顶出画面。
- 过场像电影那样拍：先细节后全貌（一只踩进镜头的靴子，然后才是人）；剪影（走过落日的身影）；越肩揭示（从他肩后升起，火山口打开）；特写给面具；动作戏用慢动作和低机位。剪辑点卡在鼓点上。
- 每个镜头只有一个主体、一个动作。人物在镜头里一定在做事：走、停、顿棍、偏头、舞花、压低重心。
- 战斗：镜头稳定、可读，自动框住猴子和牛魔王正在出招的部位；大招时自动拉远。

## 音乐与声音

- 压抑的低音、喉音吟唱、远处的钟、零落的鼓。战斗高潮时鼓才真正爆发。不是欢快的民乐。
- 唢呐类的尖亮音色只在关键时刻出现，像一声哭喊。
- 结局是雨声，配一把像古琴的拨弦。

## 禁忌

- 不要沿用《黑神话：悟空》的任何具体造型、UI、关卡或音乐。素材只取《西游记》原著和传统戏曲。
- 不要卡通、不要 Q 版、不要霓虹般的高饱和；发光要克制（必须保持战斗可读）。
- 所有游戏内文字用中文。
