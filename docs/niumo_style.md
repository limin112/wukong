# 《火焰山 · 牛魔》美术圣经（暗黑魂系）

总导演定稿。所有概念图、模型、场景、光影、镜头、音乐都以这份为准。玩法与分镜见 `docs/niumo_design.md`，模块接口见 `docs/niumo_architecture.md`。

## 总基调

衰败的神话。压抑、沉默、古老，不是热血爽片。这里的火已经烧了一千年，连火都疲倦了：大部分熔岩已经冷却结壳，只在裂缝深处透出暗红的余烬。光很少，来自熔岩底光、余烬、被浓烟遮住的暗红天空。每一处亮光都要「值得」。

## 色板

- 主体：炭黑、灰烬灰、焦褐、暗铁锈红。
- 点缀：暗淡的熔岩橙（只在裂缝、伤口、局部）、旧金（悟空的甲）、亮金（牛魔王的面具、棍、护腕）、暗红（悟空的披风和丝绳）。
- 禁止：满屏高饱和的大红大金（牛魔王的金面具、金棍、护腕除外）、亮橙色的熔岩海、霓虹般的发光。画面整体偏暗，亮部不超过两成。

## 牛魔王（白牛武僧，以 `concept/niumo_w_bull_a6.png` 为准，2026-11-13 用户定稿）

- 原著本相是大白牛：骨白色的皮，带旧伤疤，颌下和颈部有粗硬的白鬃；一对巨大的乌黑弯角，角尖包一层薄金。
- 身材极其强壮：隆起的斜方肌和肩、厚胸肌、八块腹肌、粗壮的手臂和青筋。胸、肩、双臂大面积裸露。
- 富贵只体现在面具和装备上，身上是僧人装束。克制，不要土豪感（不要满身宝石、念珠成串、织锦龙袍）：
  - 金牛脸面具：一整块亮金，细刻云纹，额头一颗小暗红石，金鼻环；
  - 混铁棍：乌黑陨铁棍身，嵌金色云纹，厚重的雕花金箍，两头金帽雕成牛头；
  - 护腕：金和乌铁，刻云纹，挂着天庭的断锁链。
- 僧人装束：暗锈红和炭灰的拼块袈裟，只搭左肩，裹住腰和腿；粗麻绳腰带；一串大颗深色木念珠。
- 在暗红的火山里，亮金只出现在面具、棍和护腕上，其余部分依然低调、暗沉。

## 悟空（黑金猿猴战神，以 `concept/niumo_w_monkey4_front.png` 为准，2026-11-13 用户定稿）

- 先是猴子，再是战士：写实的猿脸（尖耳、突出的吻部、浓密的金棕毛），不戴面具，表情冷峻警觉；额头一道细金箍。
- 黑金重甲，像实战用过的装备：黑铁甲片层层叠叠，边缘磨损、划痕、氧化，旧金包边。
  - 左肩一个夸张的金色兽首（龙/狻猊）肩甲，右肩是叠片肩甲；
  - 胸甲上有战鼓样的圆形浮雕和兽面纹，腰间一张吞兽面；
  - 暗红丝绳从肩斜拉到胸腹，打着结；腰间挂着金属饰件、布条、流苏；
  - 下身是深色战裙配鳞甲护腿，膝上兽面护膝，黑靴旧金包头。
- 破旧的暗红披风从两肩垂到小腿，从背后看是他最醒目的颜色；手腕挂着五行山的断锁链；身后一条长尾。
- 配色：黑、暗灰、铁锈为主，旧金和暗红点缀。
- 金箍棒：乌铁棍身，两头金箍（程序生成，见 `monkey.js` 的 `createStaff()`）。
- 与牛魔王的对照：他是黑金战神，牛魔王是白牛武僧；一黑一白，都带金。

## 场景：火山口里的古祭坛

- 牛魔王盘坐在火山口尽头一座半埋在火山灰里的古祭坛上。
- 战场散布着断裂的石碑（刻着褪色的符文）、倒塌的石牌坊、插在地上锈蚀的兵器和骸骨，那是之前的挑战者。
- 熔岩河是暗的：表面结着黑色的硬壳，只有裂缝和流动的边缘发光。
- 火灰像雪一样缓缓飘落；远处还有更多冒烟的火山；天被浓烟压住，只透出暗红。
- 二阶段（山崩）：山体裂开，熔岩真正喷发，天被照亮，这是全片最亮的时刻。结局下雨，雨把一切冲成灰黑色，蒸汽升起。

## 光影

- 低调（low-key）光。主光是熔岩的底光和余烬的暖光，配冷色的天光轮廓。
- 大面积的黑，剪影优先；角色靠轮廓光读出来。
- 热浪扭曲、灰雾（大气透视）让巨物的远处发虚，显得更大。
- 发光克制：只有熔岩裂缝、眼睛、受击火花和二阶段的喷发可以泛光。

## 镜头

- 巨物用仰拍；人物多放在画面下三分之一；巨物的头常常顶出画面或隐在烟里。
- 过场：慢推、慢摇、长镜头。剪辑点卡在鼓点上。
- 战斗：镜头稳定、可读，自动框住猴子和牛魔王正在出招的部位；大招时自动拉远。

## 音乐与声音

- 压抑的低音、喉音吟唱、远处的钟、零落的鼓。战斗高潮时鼓才真正爆发。不是欢快的民乐。
- 唢呐类的尖亮音色只在关键时刻出现，像一声哭喊。
- 结局是雨声，配一把像古琴的拨弦。

## 禁忌

- 不要沿用《黑神话：悟空》的任何具体造型、UI、关卡或音乐。素材只取《西游记》原著和传统戏曲。
- 不要卡通、不要 Q 版、不要高饱和、不要过度发光（必须保持战斗可读）。
- 所有游戏内文字用中文。
