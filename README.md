# 火焰山 · 牛魔

浏览器里的魂系 Boss 战：孙悟空对决火山口里盘坐千年的白牛魔王。题材取自《西游记》原著。
Three.js、ES 模块，没有构建步骤；音乐和音效全部程序合成；模型由 Tripo 生成。

```bash
npm install
node serve.mjs 5174    # 打开 http://127.0.0.1:5174/
```

先点一下页面，开场过场之后直接开打。

| 操作 | 键位 |
|---|---|
| 移动 | WASD |
| 轻击（三连） | J |
| 重击（按住蓄力） | K |
| 格挡 / 弹反 | 按住 L / 按准时机 |
| 芭蕉扇 | I |
| 翻滚 / 奔跑 | 空格点按 / 按住 |

- 看电脑自己打：`?demo`；
- 跳过开场：`?skipmv`；
- 录一段演示视频：`node tools/record_demo.mjs`。

开发说明见 [AGENTS.md](AGENTS.md)。设计文档在 `docs/`：玩法和分镜、美术设定、模块接口。
